One-time Setup Required
Connect your Supabase database so inventory syncs automatically for all staff. Takes about 5 minutes.
1
Create free Supabase account
Go to supabase.com → Sign up → New Project → name it savemore → wait ~1 min for it to start
2
Create the inventory table
In your Supabase project → click SQL Editor in the left sidebar → New query → paste this and click Run:
create table if not exists inventory (
  id bigint generated always as identity primary key,
  model text, description text, category text,
  price numeric, cost numeric,
  qty integer, qty_av integer,
  location text, vendor text,
  updated_at timestamptz default now()
);
alter table inventory enable row level security;
create policy "public read" on inventory for select using (true);
create policy "service write" on inventory for all using (true);
3
Paste your project credentials
In Supabase → Settings → API → copy Project URL and anon public key (NOT service_role)
